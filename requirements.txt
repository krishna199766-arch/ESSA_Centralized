# What Vercel installs for the serverless function in api/index.py.

# Deliberately NOT the same list as backend/requirements.txt, because the
# platform is not the same:
#
#   uvicorn      — Vercel runs the ASGI app itself; there is no server to start.
#   pytesseract  — needs a `tesseract` binary, which this runtime has not got.
#                  Extraction is vision-only here (see below).
#   pdf2image    — needs poppler, likewise absent. It was never actually called
#                  anywhere; PDFs now go to the model as documents instead.
#
# Dropping tesseract means there is no offline OCR fallback: a deployment with
# no ANTHROPIC_API_KEY cannot read an invoice at all. Everything else — GRN,
# inventory, labels, dispatch, the phone app, the shop — works regardless.
